# Fonts

The text in these files uses two fonts, which are not included in the repository.

| Font | Use | Where to get it |
|---|---|---|
| Jost Medium | "Hexagonix" and version numbers | https://fonts.google.com/specimen/Jost |
| IBM Plex Mono Regular | the prompt line in the banner | https://fonts.google.com/specimen/IBM+Plex+Mono |

Both are licensed under the SIL Open Font License 1.1.

The visible text in the SVG files is already converted to outlines, so the files look the same with or without the fonts installed.
To change the text, install the fonts, show the hidden layer whose name ends in "editável", edit it, convert it to outlines and delete the old outlines.
